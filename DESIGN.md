# Design: Your Favorite Daddy Shop

World: the shop is a DM conversation. Built 10 Oct 2026 (code-led, degraded roll, seed f10e4c63). Direction contract: .impeccable/surfaces/public-index-html.md.

## Tokens (public/styles.css :root)
- --wall #2a2de0 ultramarine chat wallpaper (page ground, 22px dot grid at 9% white)
- --wall-deep #1f22bf header, inbox pane, sheets, composer
- --in #ffffff / --in-ink #14113d / --in-meta #5f5c8a incoming bubbles
- --out #e0005b / --out-ink #fff the visitor's replies and the primary action
- --yel #ffe14d badges, read ticks, focus ring, selection only
- Single world, no dark/light variant (color-scheme: light).

## Type
Rubik 400/500/700/800/900 for everything; the line bubble is 900, clamp(36px, 9.5vw, 68px), tracking -0.035em. Mr Dafoe only for the "Daddy" avatar signature. Shirts themselves use Anton, Bowlby One, Dela Gothic One, Sedgwick Ave Display, Rubik Mono One, Bungee, Archivo Black, Mr Dafoe (design/frasi/_render.cjs).

## Components
Chat header (avatar with yellow ring, name, online status, bag with yellow badge) · inbox pane (pills Tutte/Uomo/Donna, conversation rows: round shirt crop, line, opener, price as timestamp, PICCANTE/ESAURITA flag) · bubbles (22px radius, 6px tail corner on the last of a group, meta time + read ticks) · line bubble · photo bubble with price caption · cheekiness dots · composer "reply" (size chips + "Lo voglio" send button, sticky on mobile) · typing dots · bottom sheet cart (side panel ≥900px) · checkout form inside a bubble.

## Layout
<900px one column, thread first then inbox; ≥900px 380px inbox + thread pane, each scrolling, thread column max 760px.

## Motion
Bubbles arrive (translateY 10px + scale .97, 420ms ease-out, 90ms stagger); after "Lo voglio" the reply bubble, 700ms typing dots, then the shop's confirmation. Sheet rises with the drawer curve. Everything collapses under prefers-reduced-motion.
